# Copybook 子集

## 固定格式

- 第 1–6 列：序号区，忽略。
- 第 7 列：指示符。`*` 注释、`/` 换页忽略、`-` 续行、空格为正常行；其他字符报 `CB008`。
- 第 8–72 列：正文；第 73 列以后忽略。
- 不允许制表符；非空行不足 7 列报 `CB008`。
- 续行把正文追加到上一条逻辑行，续行前无逻辑行报 `CB008`。

## 层级与名称

`01` 必须恰好一个，作为记录根；支持层级 `01,03,05,10,15,…,45,49`。
父层级必须严格小于子层级，跳级合法，层级回退必须回到已有祖先，否则 `CB004`。
字段名匹配 `^[A-Z][A-Z0-9-]*$`；重复名称、缺 PIC 的 elementary 项等结构问题均显式报错。

## PIC 与字节长度

| 写法 | 类别 | 存储长度 |
| --- | --- | --- |
| `X(n)` / `A(n)` | 字符 | `n`，缺省 `(1)` |
| `9(n)` | 无符号数值 | `n` |
| `9(n)V9(m)` | 带小数数值 | `n+m`，scale=`m` |
| `S9(n)` / `S9(n)V9(m)` | 带符号数值 | `n+m`；`SIGN IS … SEPARATE` 时再加 1 |
| `COMP-3` 数值 | 压缩十进制 | `(digits+2)//2`，符号半字节 `C/F` 正、`D` 负 |

`S9…` 若没有 `SIGN IS LEADING|TRAILING SEPARATE`，会按 overpunch 解释，而本工具明确
拒绝 overpunch：解码时该字段报 `DE001`。数值解码始终使用 `Decimal`，不经过二进制浮点。

## OCCURS 与 REDEFINES

- `OCCURS n TIMES`，`1 ≤ n ≤ 9999`；支持组和 elementary 项。`OCCURS DEPENDING ON` 拒绝，报 `CB007`。
- 展开后的叶子路径形如 `TAGS[0].TAG-VALUE`，偏移按 `index * 单次长度` 计算。
- `REDEFINES` 必须指向**同层、前面已出现**的字段；偏移与目标一致，长度不得超过目标，
  否则 `CB003` / `CB005`。组长度取各非重定义字段推进后的最大边界。

## 诊断码

| 码 | 含义 |
| --- | --- |
| `CB001` | PIC 不受支持或格式错误 |
| `CB002` | OCCURS 数量非法 |
| `CB003` | REDEFINES 目标不存在或不在前面 |
| `CB004` | 层级关系非法 |
| `CB005` | REDEFINES 比目标大 |
| `CB006` | 记录长度为 0，或根记录数量不是 1 |
| `CB007` | 未知/不支持子句、重复子句、语法错误 |
| `CB008` | 固定格式行非法（列、制表符、续行指示符） |
| `CB009` | 记录长度超过 32760 字节 |

任何 `severity=error` 的 CB 诊断都会使 `validate` 以退出码 2 结束，并输出完整字段树。

## 显式拒绝清单

`COMP-1`、`COMP-2`、浮点类型、`OCCURS DEPENDING ON`、`PIC P`、编辑型 PIC、
overpunch 符号、`RENAMES`、`COPY`、超过 32760 字节的记录，以及任何未列出的 USAGE/子句。
拒绝时给出稳定错误码，不静默降级为超集兼容。
